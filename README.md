# BabyClock

<p>
  <img src="./public/babyclock-icon.png" alt="BabyClock logo" width="120" height="120" />
</p>

BabyClock is a simple Android-first baby care reminder app for feeding, diaper changes, sleep, medicine, appointments, and custom routines. It keeps reminders local on the device and helps parents follow daily baby care routines from one calm place.
